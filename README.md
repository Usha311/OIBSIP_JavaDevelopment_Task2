# ATM Interface

## Objective

The objective of this project is to develop a console-based ATM Interface using Java that simulates basic banking operations. It allows users to securely access their account and perform common ATM transactions.

## Features

* User Authentication
* Balance Inquiry
* Cash Withdrawal
* Cash Deposit
* Money Transfer
* Transaction History
* Menu-driven Console Interface

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Scanner Class
* VS Code / IntelliJ IDEA
* JDK

## How to Run

1. Clone or download the repository.
2. Open the project in your preferred Java IDE.
3. Compile the Java files.
4. Run the `Main.java` file.
5. Follow the on-screen instructions to perform ATM operations.

## Outcome

This project helped me strengthen my understanding of Java programming, object-oriented concepts, conditional statements, loops, and user interaction by building a real-world console-based banking application.
